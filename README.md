💻 Featured project: Classroom Polling Platform
I built a classroom polling platform using Django REST Framework, Django Channels, and Vue.js to give teachers an affordable way to collect student responses and display live results.
- Teachers can create polls, and students can join and answer from their devices.
- Results update in real time.
- The backend prevents duplicate submissions and stops accepting answers once a poll closes.
- Piloted in two classrooms with around 40 students.
